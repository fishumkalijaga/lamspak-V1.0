DOCUMENT INTELLIGENCE

Pembaca FED & pemeriksa bukti

Impor DOCX, PDF yang memiliki lapisan teks, atau TXT. Pembacaan dan pencocokan awal dilakukan di perangkat Anda; dokumen tidak otomatis dikirim ke layanan AI.

01 · Impor dokumen

Gunakan FED terisi, SK, laporan kinerja, atau dokumen pendukung. Template kosong dan surat tugas asesmen tidak dapat membuktikan capaian.

Batas 18 MB per file, maksimal 8 file tiap unggahan. Pustaka DOCX/PDF dimuat dari CDN.

02 · Arsip teks dokumen

0 dokumen

Kutipan teks dan metadata tersimpan hanya di localStorage browser; batas penyimpanan browser dapat membatasi jumlah dokumen. Simpan cadangan pekerjaan secara berkala.

03 · Pemetaan kandidat

Setelah impor, klik “Petakan ke 73 indikator”. Hasil pencocokan ditampilkan bersama halaman PDF atau urutan blok DOCX sehingga dapat ditelusuri.

04 · Referensi publik & rekomendasi otomatis

Rekomendasi per indikator tersedia langsung setelah pemetaan, meskipun tidak ada dokumen yang cocok dan tanpa endpoint AI. Referensi publik menjadi pedoman normatif, bukan bukti pencapaian program studi.

05 · Koneksi AI generatif melalui proxy aman

Masukkan endpoint Cloudflare Worker yang Anda deploy dari folder worker/. Kunci API model disimpan sebagai secret Worker, jangan dimasukkan ke kode GitHub Pages. Pengiriman hanya terjadi saat tombol analisis AI per indikator diklik. Teks terpilih dapat diproses pihak penyedia AI.

Catatan keterbatasan

Rekomendasi dasar tetap rule-based; pembaca PDF/DOCX berjalan di browser dan AI opsional melalui Worker yang dikelola terpisah. GitHub Pages tidak menyediakan database multiuser atau API key aman. Hasil penilaian adalah simulasi internal, bukan penetapan peringkat oleh LAMSPAK.

Etika data & kewenangan

Aplikasi tidak terafiliasi secara resmi dengan ASPIKOM ataupun LAMSPAK. Penggunaan logo tunduk pada panduan pemilik merek. Data kerja tersimpan dalam localStorage browser.
