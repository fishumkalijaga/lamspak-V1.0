# Daftar uji penerimaan FED Review v3

1. Buka GitHub Pages: menu Review → filter memuat 12 pilihan (Semua + 11 standar), daftar seluruh 73 indikator terlihat saat Semua standar.
2. Pilih setiap standar, periksa daftar item tidak kosong, cari nomor 1 dan 73.
3. Buka Pembaca Dokumen: tanpa dokumen, terdapat 73 panel rekomendasi termasuk status Perlu bukti.
4. Unggah file DOCX, PDF teks, atau TXT: jumlah dokumen bertambah, klik Petakan, kandidat (bila ada) menunjukkan sumber dan lokasi, tanpa kecocokan tetap ada rekomendasi.
5. Pada satu item, klik Buat draf perbaikan: editor narasi revisi terisi teks dengan placeholder verifikasi.
6. Pada item yang sama klik Buat rekomendasi & narasi otomatis (AI opsional) tanpa endpoint: rekomendasi offline tampil.
7. Isi bukti dan narasi, pilih skor, ekspor JSON/CSV, refresh halaman, periksa penyimpanan lokal jika browser mengizinkan.
8. Jika Worker diaktifkan secara terpisah, uji izin CORS, token, dan respons AI tanpa pernah menyimpan API key dalam repo.
9. Periksa Copyright © 2026 ramalabs dan logo ASPIKOM kanan atas.

**Batas:** skor dan kandidat bukan keputusan resmi; sumber publik tidak menjadi bukti institusi; OCR PDF scan dan verifikasi autentisitas bukti tidak tersedia.
